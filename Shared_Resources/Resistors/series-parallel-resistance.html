Series and parallel resistance

RT = total (equivalent) resistance. R1, R2, … = individual resistances. Unit: ohm (Ω).

Series: one path

The same current passes through every resistor.

RT = R1 + R2 + R3 + …

100 Ω + 200 Ω + 300 Ω = 600 Ω

n identical resistors: RT = n × R

Check: the total is greater than any individual positive resistor.

Parallel: shared endpoints

Every branch has the same voltage.

1/RT = 1/R1 + 1/R2 + …

Add the reciprocals, then invert the sum.

1/100 + 1/200 = 0.015 → RT = 66.7 Ω

Exactly two resistors: RT = (R1 × R2)/(R1 + R2)

n identical resistors: RT = R/n

Check: the total is less than the smallest positive resistor.

Relate resistance to current

For an ohmic load: I = V/RT. At fixed voltage, greater total resistance means less total current. Use consistent units.
